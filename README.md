# ics418-agileproject
ICS 418 Agile Project - April, Lexter, Aisha and Jonas

The department plans to install two 43-inch touchscreen digital signage displays on the first and second floors of Ka Lama.

The problem we need to tackle is the need for a centralized, interactive system that allows UHMC students, faculty, and visitors to easily access business program information, building directories, job opportunities, campus announcements, and other resources. Our team will use Agile methodology to develop a functional touchscreen digital signage system that meets the Business Department's requirements.
